# Asistente de Tesis

**Caja de herramientas para Tesistas de Ciencias de la Salud**

Asistente de Tesis es una aplicación web educativa que guía a estudiantes e investigadores de Ciencias de la Salud desde la pregunta de investigación hasta el plan de análisis, y reúne las decisiones metodológicas en un borrador de metodología exportable.

## Ruta del protocolo
1. Pregunta de investigación (PECO, PICO, CoCoPop, PIRD, PFO, SPIDER) y criterios FINER.
2. Diseño del estudio.
3. Revisión ética.
4. Tamaño muestral.
5. Plan de análisis estadístico.

## Herramientas
- Calculadora 2×2.
- Verificador crítico EQUATOR.
- Mi protocolo: borrador de metodología exportable a Word, PDF o texto.

## Uso
La aplicación está contenida íntegramente en `index.html`. Puede abrirse directamente en un navegador moderno, sin conexión a internet, y no requiere instalación, backend ni base de datos.

Si se publica la carpeta completa en un servidor con HTTPS (por ejemplo, GitHub Pages o un servidor institucional), `sw.js` y `manifest.webmanifest` permiten instalarla como aplicación y usarla sin conexión después de la primera visita.

## Privacidad
Los datos se procesan y guardan únicamente en el navegador del usuario (almacenamiento local). No se envían a servidores ni se recopilan analíticas. El usuario puede borrarlos desde «Mi protocolo» o «Acerca de».

## Apoyo al proyecto
«Acerca de» incluye un botón de donación voluntaria (PayPal) y un código QR. La donación requiere conexión a internet.

## Alcance
La herramienta ofrece apoyo educativo y no sustituye la valoración metodológica o bioestadística, el software estadístico especializado ni la evaluación del Comité de Ética de Investigación.
